# +ThanPets [logo]
 +ThanPets😺 es una página de adopción de animales🐶 la cual se encarga de hacer de intermediario entre refugios🏠, personas que dan en adopción🙆,
 etc y adoptantes🙆 de una manera cercana, facil e intuitiva gracias a su aspecto visual👁️ junto con su mayor característica,
 un chat🗣️ en tiempo real entre ambas partes como si se tratase de una app de mensajería🐦.

 Esta web esta pensada sin intenciones lucrativas💵🚫 para ninguna de las partes,
 ni siquiera para la propia web dado que con la vida de nuestros amigos animales💕 no se debe negociar; porque recuerda... "Ellos son más que mascotas".
